## Project Overview
Cape Crumb Bakery is an artisan bakery in Cape Town. The website aims to increase online orders and foot traffic for sourdough bread, croissants and cupcakes. Target audience: Cape Town locals and tourists.

## Part 2 Implementation
### 2.2 Base Style
- CSS Reset: * { margin:0; padding:0; box-sizing:border-box; }
- Body with font-family, background-color, color, font-size, line-height

### 2.3 Typography
- font-family: Arial, sans-serif
- font-size using rem and em
- font-weight: 400, 500, 600, 700
- line-height: 1.6
- letter-spacing: 0.5px

### 2.4 Layout
- Flexbox: display:flex, flex-direction, justify-content:space-between, align-items:center
- Grid: display:grid, grid-template-columns, grid-template-areas, gap

### 2.5 Visual Style
- color, background-color, border, box-shadow, border-radius
- Pseudo-classes: a:hover, a:focus, a:active

### 3.1-3.3 Responsive
- Breakpoints: @media (max-width: 768px) and @media (max-width: 480px)
- Relative units: rem, em, %
- Responsive images: srcset and sizes attributes used in index.html
